## 🚨 Priority Rules

### Always Prioritize:
1. ✅ **Working Code** - Must run without errors
2. ✅ **Clear Documentation** - Every example explained
3. ✅ **Testing** - Everything tested before commit
4. ✅ **Consistency** - Match existing style

### Can Be Deferred:
- 🟡 Perfect formatting (get it working first)
- 🟡 Advanced features (start simple)
- 🟡 Multiple approaches (one good way is enough)

---

## 💡 Quick Tips

### For Code Examples
- Start with simplest possible version
- Add comments for every non-obvious line
- Include error handling
- Show expected output
- Provide requirements.txt

### For Notebooks
- Break into small, digestible cells
- Add markdown explanations between code
- Show outputs and visualizations
- Test on Google Colab
- Include "Run All" success test

### For Documentation
- Use consistent emoji system
- Keep paragraphs short
- Use bullet points
- Add code blocks with syntax highlighting
- Include links to relevant sections
