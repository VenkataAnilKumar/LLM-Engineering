1. **IDE**: VS Code

4. **Monitoring**: LangSmith (free tier)
5. **Notebooks**: Google Colab (free GPU)

### For Intermediate Developers
**Professional Setup:**
1. **IDE**: VS Code or Cursor
2. **Extensions**: GitHub Copilot
3. **Monitoring**: Phoenix (self-hosted) or LangFuse
4. **Tracking**: Weights & Biases

1. **IDE**: VS Code with team extensions

## 💡 Productivity Tips

**VS Code Power User:**
- Install `Python`, `Jupyter`, `Continue`, `GitLens`
- Use workspace settings for project consistency
- Set up snippets for common patterns
- Use tasks for automated workflows

**CLI Efficiency:**
- Alias frequent LLM commands
- Pipe outputs between tools (e.g., `llm | pbcopy`)
- Use `mods` for terminal workflows
- Set up shell completions

**Monitoring Best Practices:**
- Log every LLM call in development
- Track token usage and costs
- Set up alerts for failures
- Version prompts alongside code

**Testing Workflow:**
- Write tests before deploying
- Use `promptfoo` for A/B testing prompts
- Automate evaluation in CI/CD
- Collect production feedback
