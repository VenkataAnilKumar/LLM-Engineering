- **Link**: [discuss.huggingface.co](https://discuss.huggingface.co/)

- **Response Time**: Usually < 24 hours

### **GitHub Issues**
- **Best For**: Library bugs, feature requests
- **Projects**: Transformers, LangChain, LlamaIndex, Ollama
- **Tip**: Search existing issues first

### **Reddit**
- **r/LocalLLaMA**: Hardware, local deployment

### **Discord**
- **Best For**: Real-time help, quick questions
- **Most Active**: Hugging Face, LangChain, LocalLLaMA
- **Tip**: Use search before asking

## 🌟 Community Etiquette

### **Asking Good Questions**

1. **Search First**: Check docs, issues, forums
2. **Be Specific**: Include error messages, code snippets
3. **Show Effort**: What have you tried?
4. **Minimal Example**: Simplify to core problem
5. **Environment**: Python version, library versions

### **Giving Back**

- Answer questions when you can
- Share your learnings (blog posts, tutorials)
- Contribute to open source
- Report bugs with reproducible examples
- Star/share helpful projects

## 🎯 Getting Started

### **Week 1: Join Communities**
- ✅ Join 2-3 Discord servers (Hugging Face, LangChain)
- ✅ Subscribe to 1-2 newsletters (The Batch, TLDR AI)
- ✅ Follow 5-10 people on Twitter/X

### **Week 2: Engage**
- ✅ Read daily updates
- ✅ Answer one question in Discord/Reddit
- ✅ Star helpful GitHub projects

### **Week 3: Contribute**
- ✅ Make first open-source contribution
- ✅ Share your learning (blog, tweet)
- ✅ Attend virtual meetup

### **Ongoing**
- 📧 Read newsletters (10 min/day)
- 💬 Check Discord/Reddit (15 min/day)
- 🐦 Browse Twitter/X (15 min/day)
- 📝 Write about learnings (1 hour/week)

---

## 🚀 Pro Tips

1. **Don't Join Everything**: Start with 2-3 communities, expand gradually
2. **Give Before You Take**: Answer questions, share resources
3. **Build in Public**: Share your projects, learnings
4. **Network**: DM people doing interesting work
5. **Local Meetups**: In-person connections are valuable
6. **Stay Humble**: Everyone's learning, be respectful
